# wilds-wdl-writer
An LLM-based tool for building custom WDL workflows using validated components from the WILDS WDL Library

Read the [Design Specifications](docs/mvp_design_spec.md)

Requirements:
- `pandas`
- `numpy`
- `chromadb`
- `ollama`
- `rapidfuzz`
- `llama-index-core`
- `llama-index-embeddings-huggingface`
